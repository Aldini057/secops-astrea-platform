# SecOps Astrea Platform (SOAR + VulnOps + Threat Intelligence)

Plataforma unificada de orquestación de seguridad, detección e inteligencia de vulnerabilidades.

## Módulos
- **Detección e Ingesta:** Splunk SIEM / Webhooks.
- **Orquestación & SOAR:** n8n Workflows.
- **Vulnerability Intel:** Microservicio NVD-Analyst (FastAPI + NIST API).
- **Analytics & Visibilidad:** BID Dashboard (Streamlit / Plotly).
